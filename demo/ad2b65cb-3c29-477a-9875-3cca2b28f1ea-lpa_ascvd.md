# LPA–ASCVD

## 0. 基本信息

Record ID:
LPA-ASCVD

疾病领域:
ASCVD（动脉粥样硬化性心血管疾病）

表型 / 生物标志物:
脂蛋白(a)（Lp(a), lipoprotein(a)）

主要靶点:
LPA

治疗假设定义:
通过降低 LPA 表达或减少 apo(a) 生成，降低血浆 Lp(a) 水平，从而可能降低 Lp(a) 升高人群的 ASCVD 残余风险。

最后更新时间:
2026-08-17


## 1. Scientific Readiness｜科学成熟度

Scientific Readiness 定义:
评估该靶点与疾病或关键表型之间是否存在清晰、可信的生物学因果关系。

核心判断:
LPA 是 Lp(a)-lowering 最直接的靶点。LPA 编码 apo(a)，apo(a) 是 Lp(a) 的关键组成部分。人类遗传学证据支持 LPA locus 是影响 Lp(a) 水平的主要遗传因素，同时 Lp(a) 升高与 ASCVD 风险增加相关，并具有因果风险因素特征。

主要支持证据:
1. LPA 编码 apo(a)，apo(a) 是 Lp(a) 的关键组成部分。
2. LPA locus 是影响 Lp(a) 水平的主要遗传因素。
3. Lp(a) 升高与 ASCVD 风险增加相关，并具有因果风险因素特征。

Scientific Readiness 评级:
强

Scientific Readiness 总结:
LPA 是 Lp(a)-lowering 最直接、靶点归因最清楚的靶点。其科学成熟度较强，但药物降低 Lp(a) 是否带来明确 ASCVD outcome benefit 仍需临床结果支持。


## 2. Tractability｜可干预性

Tractability 定义:
评估该靶点是否可以通过药物或其他治疗 modality 被安全、有效、可开发地干预。

核心判断:
LPA 的干预方向比较明确，即降低 LPA 表达或减少 apo(a) 生成，从而降低 Lp(a)。根据 Open Targets tractability 信息，LPA 具有一定可干预性信号，包括 small molecule 的结构 / druggable family 支持，以及 antibody 的蛋白定位 / 分泌相关支持。Open Targets Drugs and Clinical Candidates 信息显示已有 LPA 相关临床 III 期候选药物，

干预方向:
降低表达 / 降低 apo(a) / 降低 Lp(a)

疗效窗口:
初步形成 / 待临床 outcome 验证

安全性风险:
中等 / 仍需长期验证; 已知信号：olpasiran Phase 2 观察到轻度高血糖及新发糖尿病风险增加的迹象，是 Phase 3 中需重点关注的安全性问题；pelacarsen 目前未见类似代谢信号，主要不良事件为注射部位反应。


可行 modality:
- small molecule: 有结构和 druggable family 层面支持；已有临床阶段验证——muvalaplin（口服，Lilly）已进入 Phase III，机制为阻断 apo(a)-apoB 组装。
- antibody: 有蛋白定位 / 分泌相关支持；
- siRNA / ASO: 已有两个进入 Phase III 的管线（pelacarsen、olpasiran），另有 lepodisiran（Phase III）及 zerlasiran（Phase II）在研，是目前进展最快的 modality 类别。

主要不确定性:
1. 药物降低 Lp(a) 后是否能明确降低 ASCVD events 仍需临床 outcome evidence。
2. 长期安全性和极低 Lp(a) 水平的潜在风险仍需验证。

Tractability 评级:
中等

Tractability 总结:
LPA 有一定可干预性支持；目前已有 4 个管线进入或接近 Phase III，说明 LPA 的可干预性在实践中已被多种 modality（ASO、siRNA、口服小分子）验证

## 3. Competitive Landscape｜竞争格局

Competitive Landscape 定义:
评估该靶点或相关机制是否已有临床开发管线、获批疗法，以及是否仍存在差异化开发机会。

核心判断:
Lp(a)-lowering 是近年来药企高度关注的方向，截止2026年8月，已有 4 个 Lp(a)-lowering 候选药物处于 Phase III，覆盖 3 种作用机制和 2 种给药途径（皮下注射 / 口服）。

已获批疗法:
暂无明确 Lp(a)-specific 且 outcome-validated 的常规获批疗法，需继续核验。

临床开发管线:
有

主要公司 / 资产:
1. Novartis / Pelacarsen / ASO, 皮下注射/ 临床III期中
2. Amgen / Olpasiran / siRNA，皮下注射/ 临床III期中
3. Eli Lilly / Lepodisiran / siRNA，长效/ 临床III期中
4. Eli Lilly / Muvalaplin / 口服小分子/ 临床III中
5. Silence Therapeutics / Zerlasiran / siRNA / 临床II期中

竞争格局:
高度活跃，已进入多资产 Phase III 竞速阶段

差异化机会:
给药频率/途径：muvalaplin 作为唯一口服选择，若疗效和安全性数据支持，可能在依从性上形成差异化；但这条路线已被 Lilly 占据，新进入者较难复制。
降低幅度、安全性（尤其代谢相关信号）、患者分层、Lp(a) 检测路径、中国/东亚市场定位与价格可及性，仍是相对开放的差异化维度——尤其是中国 Lp(a) 检测渗透率低、且现有管线资产均来自跨国药企，本土化和东亚人群数据是潜在空白。

主要战略阻碍:
1. 多个大药企已经布局。
2. ASCVD outcome evidence 仍需跟踪。
3. 新进入者需要明确差异化。

Competitive Landscape 总结:
LPA / Lp(a)-lowering 是高度活跃的领域，目前有 4 个资产处于 Phase III 阶段。是否值得新项目进入，很大程度上取决于（a）pelacarsen HORIZON 结果何时公布及其方向，（b）新项目能否在已被跨国药企占据的 modality 空间之外找到差异化（如东亚人群数据、检测可及性、价格）。


## 4. Target Nomination｜靶点提名

靶点提名总结定义:
综合科学成熟度、可干预性和竞争格局，判断该靶点是否值得进一步验证、立项或观察。

最终建议:
需进一步验证 / 可考虑提名

最终判断:
LPA 是 Lp(a)-lowering 最直接、最清楚的靶点，科学成熟度较强，并且处于药企积极布局的方向。当前主要限制是 ASCVD outcome benefit、长期安全性和竞争差异化仍需进一步确认。

主要支持因素:
1. LPA 靶点归因清楚，直接对应 Lp(a)-lowering 治疗假设。
2. Lp(a) 与 ASCVD 风险关系较强，并具有因果风险因素特征。
3. LPA / Lp(a) 是药企积极布局的 emerging area，已有 4 个资产（3 种机制、2 种给药途径）进入 Phase III，说明该方向的临床开发热度和技术可行性已获多重验证。

关键 blocker:
1. ASCVD outcome benefit 仍需最终临床证据支持。
2. 长期安全性和极低 Lp(a) 水平的潜在风险仍需验证。
3. 赛道已有 4 个 Phase III 资产，新项目需要明确差异化。

下一步建议:
1. 如果评估新项目，需要重点比较其相对现有 4 个 Lp(a)-lowering 项目的差异化优势，尤其关注东亚人群数据、检测可及性和价格定位等 modality 之外的差异化维度。
2. 密切关注 pelacarsen Lp(a)HORIZON 结果公布时间和方向，作为影响整个赛道决策信心的关键触发事件。
