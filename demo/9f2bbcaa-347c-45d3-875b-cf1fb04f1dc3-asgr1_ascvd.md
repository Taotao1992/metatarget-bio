# ASGR1–ASCVD

## 0. 基本信息

Record ID:
ASGR1-ASCVD

疾病领域:
ASCVD（动脉粥样硬化性心血管疾病）

表型 / 生物标志物:
非 HDL 胆固醇（non-HDL-C）、LDL-C

主要靶点:
ASGR1（asialoglycoprotein receptor 1，去唾液酸糖蛋白受体 1）

治疗假设定义:
通过抑制或降低肝细胞 ASGR1 功能，模拟人群中天然存在的 ASGR1 loss-of-function 变异，从而降低 non-HDL-C，并可能降低 CAD / ASCVD 风险。

最后更新时间:
2026-08-25


## 1. Scientific Readiness｜科学成熟度

Scientific Readiness 定义:
评估该靶点与疾病或关键表型之间是否存在清晰、可信的生物学因果关系。

核心判断:
ASGR1 是一个有人类遗传学支持的脂质代谢候选靶点。deCODE Genetics 2016 年 NEJM 研究发现，ASGR1 del12 loss-of-function 变异携带者 non-HDL-C 更低，CAD 风险也更低；另一个罕见 LoF 变异 p.W158X 也支持 non-HDL-C 降低方向。这说明降低 ASGR1 功能可能具有心血管保护作用。不过，目前还不清楚药物抑制 ASGR1 是否能复制这种遗传学观察到的保护效应。

主要支持证据:
1. ASGR1 del12 变异与 non-HDL-C 降低和 CAD 风险降低相关。
2. p.W158X 罕见 LoF 变异支持 non-HDL-C 降低方向。
3. ASGR1 LoF 的保护效应可能不完全由 non-HDL-C 降低解释，提示可能存在额外机制。

主要不确定性:
1. ASGR1 loss-of-function 保护效应的具体机制还没有完全解释清楚。
2. del12 携带者伴随 ALP 和维生素 B12 变化，这些变化的长期安全性含义需要进一步评估。
3. 目前缺少公开数据证明药物抑制 ASGR1 能降低 non-HDL-C 或 CAD / ASCVD 风险。

Scientific Readiness 评级:
中等偏强

Scientific Readiness 总结:
ASGR1 的人类遗传学证据比较有吸引力，支持它作为 ASCVD / lipid 方向的候选靶点继续验证。但它的机制清晰度和药物验证程度仍低于 PCSK9 / LPA。


## 2. Tractability｜可干预性

Tractability 定义:
评估该靶点是否可以通过药物或其他治疗 modality 被安全、有效、可开发地干预。

核心判断:
ASGR1 主要在肝细胞表达，是一个膜受体蛋白，理论上具有一定药物可及性。Amgen 的 AMG 529 是抗 ASGR1 单抗，已经完成 Phase 1，并观察到与 ASGR1 抑制一致的 ALP biomarker 变化。这说明药物阻断 ASGR1 在人体中至少是可做到的。但目前没有看到公开的脂质疗效、长期安全性或 ASCVD outcome 数据。

干预方向:
抑制 / 降低 ASGR1 功能

疗效窗口:
临床早期 / 尚未建立

安全性风险:
中等 / 需长期验证

可行 modality:
- antibody: AMG 529 已完成 Phase 1，说明人体中可以实现 ASGR1 阻断；但后续开发状态不明。
- small molecule: 理论上可能，但目前没有看到明确进入临床阶段的 ASGR1 小分子拮抗剂。
- ASO / siRNA: 理论上可能，但需要注意不能简单依赖 ASGR1 / ASGPR-GalNAc 递送通路。
- 碱基编辑 / 基因编辑: 有早期概念价值，但距离常规 ASCVD 开发还比较远。

主要不确定性:
1. AMG 529 是否继续推进，以及为什么没有看到后续开发信息，需要核验。
2. 药物抑制 ASGR1 是否真的能降低 non-HDL-C / ASCVD risk 尚未证明。
3. 长期抑制 ASGR1 的安全性仍不清楚。
4. ASO / siRNA 递送策略有这个靶点特有的技术挑战。

Tractability 评级:
中等

Tractability 总结:
ASGR1 不是完全没有人体先例：AMG 529 已经证明可以在人体中阻断 ASGR1，并产生预期方向的 biomarker 变化。但现在缺少脂质疗效和长期安全性数据，因此只能认为它具备一定可干预性，仍需要进一步验证。


## 3. Competitive Landscape｜竞争格局

Competitive Landscape 定义:
评估该靶点或相关机制是否已有临床开发管线、获批疗法，以及是否仍存在差异化开发机会。

核心判断:
ASGR1 的竞争格局相对清淡，但不是完全空白。AMG 529 是目前最相关的直接 ASGR1 inhibition 资产，已完成 Phase 1，但后续状态不明。需要特别区分两类资产：一类是真正把 ASGR1 当作治疗靶点来抑制，另一类只是利用 ASGR1 作为肝脏递送 / 归巢机制。后者不应直接视为 ASCVD / lipid 竞争资产。

已获批疗法:
无

临床开发管线:
早期 / 需核验

主要公司 / 资产:
1. Amgen / AMG 529 / 抗 ASGR1 单抗 / Phase 1 完成，后续状态不明
2. SZN-043 / Surrozen / ASGR1-mediated liver targeting / 非 ASCVD 降脂资产
3. SBT8230 / Silverback Therapeutics / ASGR1-mediated liver targeting / 非 ASCVD 降脂资产
4. 其他 ASGR1 相关资产需区分“治疗靶点”和“递送机制”

竞争格局:
早期 / 低竞争 / 需核验

差异化机会:
1. 如果 AMG 529 停滞不是因为疗效或安全性问题，ASGR1 可能仍有开发窗口。
2. 新项目可以围绕 ASGR1 抑制机制、长期安全性、递送策略和 IP 空间寻找差异化。
3. 如果面向中国 / 东亚市场，本地人群数据可以作为补充，用于评估变异频率、安全性表型和市场定位。

主要战略阻碍:
1. AMG 529 后续状态和停滞原因不明。
2. Amgen / deCODE 可能已有核心遗传学和抗体相关 IP 布局。
3. 缺少 ASGR1-directed therapy 的脂质疗效和 outcome evidence。
4. 长期安全性和 ALP / B12 相关信号需要系统评估。

Competitive Landscape 总结:
ASGR1 的机会和风险都集中在 AMG 529 上。它说明这个方向不是完全没人做过，但也提出了一个关键问题：为什么 Phase 1 之后没有看到明确后续进展？这个问题需要先查清楚，才能判断 ASGR1 是被低估的机会，还是别人已经试过但没有继续推进的方向。


## 4. Target Nomination｜靶点提名

靶点提名总结定义:
综合科学成熟度、可干预性和竞争格局，判断该靶点是否值得进一步验证、立项或观察。

最终建议:
需进一步验证 / 优先验证候选

最终判断:
ASGR1 的吸引力在于：有人类遗传学支持，公开竞争不多，而且已有 AMG 529 的人体 Phase 1 先例。它不像 PCSK9 那样成熟拥挤，也不像 LPA 那样已有多个 Phase III 资产。但它的转化路径还不清楚，尤其需要弄清 AMG 529 的真实开发状态、是否有脂质疗效数据、长期安全性和 IP 空间。

主要支持因素:
1. ASGR1 LoF 证据支持 non-HDL-C 降低和 CAD 风险降低。
2. AMG 529 已有 Phase 1 人体数据，说明并非完全无临床先例。
3. 直接以 ASGR1 inhibition 降脂为目的的公开竞争较少。

关键 blocker:
1. 缺少公开脂质疗效、长期安全性和 ASCVD outcome 数据。
2. AMG 529 后续状态和停滞原因未知。
3. ASGR1 相关递送机制容易与真正 therapeutic target 混淆。
4. IP、递送策略和长期安全性仍需尽调。

下一步建议:
1. 优先核验 AMG 529 的后续状态、专利和停滞原因。
2. 系统整理 ASGR1 LoF 变异与 non-HDL-C、CAD、ALP、维生素 B12 及其他安全性表型的证据。
3. 区分 ASGR1 作为治疗靶点与 ASGR1 作为肝脏递送受体的不同资产。
4. 如果面向中国 / 东亚市场，可补充本地人群中的变异频率和安全性表型分析。
