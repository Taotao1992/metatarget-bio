# ANGPTL3–ASCVD

## 0. 基本信息

Record ID:
ANGPTL3-ASCVD

疾病领域:
ASCVD（动脉粥样硬化性心血管疾病）

表型 / 生物标志物:
LDL-C、甘油三酯（TG）、非 HDL 胆固醇（non-HDL-C）、富含甘油三酯脂蛋白（TRL）

主要靶点:
ANGPTL3（angiopoietin-like 3）

治疗假设定义:
通过抑制或降低 ANGPTL3 功能，解除其对脂蛋白代谢相关通路的抑制，从而降低 LDL-C、TG、non-HDL-C 等致动脉粥样硬化脂质表型，并可能降低 ASCVD 风险。目前最明确的获批适应症是 HoFH（纯合子家族性高胆固醇血症），其价值在于 ANGPTL3 抑制的降 LDL-C 作用可部分不依赖 LDL receptor，可作为传统降脂疗法的补充；这不能直接等同于已证明可降低广泛 ASCVD 人群的心血管事件风险。

最后更新时间:
2026-09-02


## 1. Scientific Readiness｜科学成熟度

Scientific Readiness 定义:
评估该靶点与疾病或关键表型之间是否存在清晰、可信的生物学因果关系。

核心判断:
ANGPTL3 是人类遗传学支持较强的脂质代谢靶点。ANGPTL3 loss-of-function 变异与较低 TG、LDL-C 和 HDL-C 相关，并与较低冠心病风险相关，支持降低 ANGPTL3 功能具有心血管保护作用。相比 APOC3，ANGPTL3 的脂质影响更广，同时覆盖 LDL-C 和 TG；相比 PCSK9，其广泛 ASCVD outcome evidence 仍不够成熟。

主要支持证据:
1. ANGPTL3 loss-of-function 变异与 TG、LDL-C 等脂质水平降低相关。
2. ANGPTL3 loss-of-function 变异与冠心病风险降低相关。
3. ANGPTL3 抑制具有 LDL receptor-independent 降 LDL-C 特点，在 HoFH 等特殊人群中具有明确开发价值。

Scientific Readiness 评级:
强

Scientific Readiness 总结:
ANGPTL3 具有较强人类遗传学和脂质生物学支持，是 ASCVD / dyslipidemia 方向较成熟的靶点；但其广泛 ASCVD outcome evidence 仍不如 PCSK9 成熟。


## 2. Tractability｜可干预性

Tractability 定义:
评估该靶点是否可以通过药物或其他治疗 modality 被安全、有效、可开发地干预。

核心判断:
ANGPTL3 的干预方向明确，即抑制或降低 ANGPTL3 功能。该靶点已有抗体药物获批，并有 ASO、siRNA 和基因编辑等开发路径，说明可干预性较强。但不同 modality 的开发结果并不一致，部分 RNA 药物项目已因疗效、安全性或商业考虑停止推进。

干预方向:
抑制 / 降低功能或表达

疗效窗口:
已确立（HoFH）/ 待临床 outcome 验证（广泛 ASCVD）

安全性风险:
中等 / 需长期验证

可行 modality:
- antibody: 已获批。evinacumab 已获 FDA 批准作为 HoFH 的 add-on therapy，用于降低 LDL-C。
- ASO / siRNA: 有临床开发先例，但结果分化。vupanorsen 曾进入 Phase IIb 但项目已停止；zodasiran 已进入 Phase 3（HoFH 适应症 YOSEMITE 研究已完成入组，混合型血脂异常适应症 ARCHES-2 结果已发表），是目前进展最快的 ANGPTL3 资产；solbinsiran 处于 Phase 2。
- small molecule: 无明确临床阶段项目，需进一步核验。
- PROTAC / degrader: 无明显信号，不作为主要 modality。
- 基因编辑: 有早期临床探索价值，但长期不可逆或半永久性干预需要更高安全性门槛。

主要不确定性:
1. 广泛 ASCVD 人群中，ANGPTL3 抑制能否带来明确 cardiovascular outcome benefit 仍需验证。
2. RNA-based modality 的长期安全性和肝脏相关风险需要谨慎评估。
3. vupanorsen 停止推进提示不能因已有获批抗体而自动推断所有 modality 都可行。
4. 基因编辑路径的安全性、可逆性和适用人群门槛较高。

Tractability 评级:
高

Tractability 总结:
ANGPTL3 已有获批抗体药物和多个 RNA / 基因编辑方向的开发项目，可干预性较强，开发路径比 ASGR1 更成熟；但相比 PCSK9，其广泛 ASCVD outcome evidence 仍需进一步明确。


## 3. Competitive Landscape｜竞争格局

Competitive Landscape 定义:
评估该靶点或相关机制是否已有临床开发管线、获批疗法，以及是否仍存在差异化开发机会。

核心判断:
ANGPTL3 已进入获批药物和多 modality 开发阶段。当前最明确的获批适应症是 HoFH，代表药物是 Regeneron 的 evinacumab。RNA 药物方向进展和命运不同：vupanorsen 已停止推进，zodasiran 和 solbinsiran 仍代表 ANGPTL3 RNA interference 的开发方向。整体竞争格局活跃，但不像 PCSK9 那样完全成熟。

已获批疗法:
有

临床开发管线:
有

主要公司 / 资产:
1. Regeneron / Evkeeza, evinacumab / ANGPTL3 monoclonal antibody / FDA 已批准用于 HoFH add-on LDL-C lowering
2. Ionis / Pfizer / vupanorsen / ANGPTL3 ASO / Phase IIb 后项目停止推进
3. Arrowhead / zodasiran / ANGPTL3-targeting siRNA / Phase 3（HoFH 及混合型血脂异常适应症）
4. Eli Lilly / solbinsiran / ANGPTL3-targeting siRNA / Phase 2
5. Verve Therapeutics / ANGPTL3 基因编辑项目 / 早期临床探索，需进一步核验具体阶段和状态

竞争格局:
活跃 / 已有获批药物 / 多 modality 探索中

差异化机会:
HoFH 以外更大 dyslipidemia / ASCVD residual risk 人群的适应症扩展；LDL receptor-independent 机制在特定高风险患者中的定位；抗体、siRNA、ASO、基因编辑之间在疗效幅度、给药频率、安全性、可逆性和成本上的差异化；与 PCSK9、APOC3、LPA、GLP-1 等路径的联合或患者分层定位。

主要战略阻碍:
1. 已有 evinacumab 获批，新进入者需要明确差异化。
2. vupanorsen 停止推进提示 RNA modality 或广泛人群开发可能存在挑战。
3. 广泛 ASCVD outcome benefit 尚未成为成熟定论。
4. 不同 modality 的安全性、可逆性和长期使用场景差异较大。
5. HoFH 市场较小，商业空间取决于能否扩展到更大人群。

Competitive Landscape 总结:
ANGPTL3 是已被药物开发验证、但仍在寻找更大适应症空间的活跃靶点。它比 ASGR1 更成熟，也比 LPA 更早已有获批药物；新项目能否进入，取决于能否在 HoFH 之外找到清晰人群定位，并证明相对现有降脂路径的差异化价值。


## 4. Target Nomination｜靶点提名

靶点提名总结定义:
综合科学成熟度、可干预性和竞争格局，判断该靶点是否值得进一步验证、立项或观察。

最终建议:
持续观察 / 需进一步验证

最终判断:
ANGPTL3 是科学和药物开发基础都较强的脂质代谢靶点，有人类遗传学支持，也已有获批抗体药物，靶点方向和可干预性较清楚。但对更广泛 ASCVD 人群来说，关键问题仍是 ANGPTL3 抑制能否带来明确 cardiovascular outcome benefit，以及新项目能否在已有抗体、RNA 药物和基因编辑路径之外形成差异化。

主要支持因素:
1. ANGPTL3 LoF 证据支持 TG、LDL-C 降低和冠心病风险降低。
2. 干预方向明确，即抑制或降低 ANGPTL3 功能。
3. 已有 ANGPTL3-targeting antibody 获批，可干预性较强。
4. LDL receptor-independent 降 LDL-C 机制在 HoFH 等特殊人群中具有明确价值。

关键 blocker:
1. 广泛 ASCVD outcome benefit 仍需进一步确认。
2. 已有获批药物和多个临床开发路径，新进入者需要明确差异化。
3. vupanorsen 停止推进提示部分 modality / 适应症扩展存在现实挑战。
4. HoFH 市场较小，商业价值取决于能否扩展到更大 dyslipidemia / ASCVD residual risk 人群。
5. 长期安全性、价格和支付路径仍需评估。

下一步建议:
1. 系统整理 ANGPTL3 LoF genetics、LDL-C / TG / HDL-C、HoFH 和 ASCVD outcome 之间的证据链。
2. 比较 evinacumab、vupanorsen、zodasiran、solbinsiran 和 ANGPTL3 基因编辑项目的适应症、疗效、安全性、给药频率和商业定位。
3. 重点核验 vupanorsen 停止推进的原因，判断这是否影响 ANGPTL3 作为靶点本身，还是特定 modality / 适应症 / 分子的问题。
4. 如果评估新项目，需要判断其是否能相对已有抗体、RNA 药物或基因编辑路径形成明确差异化。

决策信心:
中到高
