# PCSK9–ASCVD

## 0. 基本信息

Record ID:
PCSK9-ASCVD

疾病领域:
ASCVD（动脉粥样硬化性心血管疾病）

表型 / 生物标志物:
LDL-C

主要靶点:
PCSK9

治疗假设定义:
通过抑制 PCSK9 功能，提高 LDL receptor recycling，降低 LDL-C 水平，从而降低 ASCVD 风险。

最后更新时间:
2026-08-17


## 1. Scientific Readiness｜科学成熟度

Scientific Readiness 定义:
评估该靶点与疾病或关键表型之间是否存在清晰、可信的生物学因果关系。

核心判断:
PCSK9 是 ASCVD / LDL-C 方向中科学成熟度很高的靶点。人类遗传学证据支持 PCSK9 功能降低与 LDL-C 降低和 CHD / ASCVD 风险降低相关。靶点归因清楚，作用机制明确，疾病相关表型 LDL-C 也是 ASCVD 的明确因果风险因素。

主要支持证据:
1. PCSK9 loss-of-function / reduced-function 变异支持 LDL-C 降低。
2. PCSK9 遗传证据直接指向 PCSK9 本身，而不是附近 locus。
3. LDL-C 与 ASCVD 风险之间存在明确因果关系。

Scientific Readiness 评级:
强

Scientific Readiness 总结:
PCSK9 是遗传学、机制和疾病因果关系都非常清楚的成熟 ASCVD 靶点。


## 2. Tractability｜可干预性

Tractability 定义:
评估该靶点是否可以通过药物或其他治疗 modality 被安全、有效、可开发地干预。

核心判断:
PCSK9 的干预方向明确，即抑制或降低其功能。该靶点已经被多种药物 modality 验证，说明可成药性高，疗效窗口和临床可干预性较清楚。安全性整体相对可接受，但新 modality 仍需单独评估。

干预方向:
抑制 / 降低功能

疗效窗口:
已确立

安全性风险:
低到中等

可行 modality:
- small molecule: 可行，有结构、ligand 和 pocket 支持。
- antibody: 可行，有获批药物支持。
- PROTAC / degrader: 有部分数据库 / 小分子结合支持；无临床或获批支持。
- 其他 modality: 有临床 II 期或 III 期药物支持。

主要不确定性:
1. 新 modality 的长期安全性和开发可行性。
2. 与已有疗法相比是否有足够差异化。

Tractability 评级:
高

Tractability 总结:
PCSK9 是高度可干预靶点。对新项目来说，难点不在于能不能干预，而在于是否还能做出有意义的差异化。


## 3. Competitive Landscape｜竞争格局

Competitive Landscape 定义:
评估该靶点或相关机制是否已有临床开发管线、获批疗法，以及是否仍存在差异化开发机会。

核心判断:
PCSK9 是成熟且竞争拥挤的靶点。已有 antibody、siRNA 和口服 PCSK9 inhibitor 资产，说明靶点被充分验证，但也意味着新进入者门槛高。

已获批疗法:
有

临床开发管线:
有

主要公司 / 资产:
1. Amgen / Repatha, evolocumab / PCSK9 monoclonal antibody / 已获批
2. Sanofi-Regeneron / Praluent, alirocumab / PCSK9 monoclonal antibody / 已获批
3. Novartis / Leqvio, inclisiran / PCSK9-targeting siRNA / 已获批
4. Merck / Lipfendra, enlicitide / oral PCSK9 inhibitor / FDA 2026 批准
5. 君实生物 / 昂戈瑞西单抗, ongericimab / PCSK9 monoclonal antibody / 中国获批，需进一步核验适应症和商业状态
6. 信达生物 / 信必乐, tafolecimab / PCSK9 monoclonal antibody / 中国获批，需进一步核验适应症和商业状态

竞争格局:
成熟 / 拥挤

差异化机会:
可能来自更低成本、更长给药间隔、更好依从性、口服便利性、中国 / 东亚市场可及性、医保支付路径、患者分层或联合用药策略。

主要战略阻碍:
1. 全球已有多个成熟获批产品。
2. 中国市场也已有本土 PCSK9 antibody 资产。
3. 新进入者需要非常清楚的 clinical、modality、成本或市场差异化。
4. 靶点本身已高度验证，创新性不在 target discovery，而在产品形态和商业路径。

Competitive Landscape 总结:
PCSK9 是 validated but crowded target。


## 4. Target Nomination｜靶点提名

靶点提名总结定义:
综合科学成熟度、可干预性和竞争格局，判断该靶点是否值得进一步验证、立项或观察。

最终建议:
持续观察

最终判断:
PCSK9 是一个科学成熟度强、可干预性高的 ASCVD 靶点。人类遗传学、靶点归因、干预方向和 LDL-C 疾病因果关系都比较清楚，同时已有成熟药物验证其可干预性。但由于 PCSK9 竞争格局已经成熟且拥挤，新项目是否值得推进主要取决于是否能形成明确的临床、modality、成本或市场差异化。

主要支持因素:
1. PCSK9 人类遗传学证据强，靶点归因清楚，遗传证据直接指向 PCSK9。
2. PCSK9 具有较强可干预性，尤其已有抗体药物获批。

关键 blocker:
1. PCSK9 已有成熟获批疗法，竞争格局拥挤。
2. 新进入者需要证明明确差异化，而不能只是重复已有 PCSK9-lowering 方案。
3. 创新机会更多来自 modality、给药方式、成本、可及性或特定市场定位，而不是靶点本身的新颖性。

下一步建议:
1. 如果评估新项目，需要重点比较其相对现有 PCSK9 药物的差异化优势。

决策信心:
高
